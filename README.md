# iiko API

Небольшая панель для вызова нужных методов iiko Transport, Яндекс Еды и Магнита из браузера.

- Секрет iiko остаётся в Docker-контейнере.
- Токены и ответы живут только в памяти вкладки браузера и пропадают после обновления страницы.
- Сохранённые API-логины хранятся только в `localStorage` браузера; на сервер они не записываются и не видны другим. При очистке кеша сайта - пропадут! 

## Запуск

На сервере создайте отдельный каталог и скопируйте туда содержимое этого проекта.

Создайте файл `.env` рядом с `docker-compose.yml` на основе `.env.example`:

```
IIKO_APP_ID=ваш_appId
IIKO_CLIENT_SECRET=ваш_clientSecret
PORT=3000
```

Затем запустите:

```bash
docker compose up -d --build
```

Проверка локально на сервере:

```bash
curl http://127.0.0.1:3000
```
