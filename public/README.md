# 🍽️ iiko API
Веб-интерфейс для работы с API iiko для сотрудников тех. поддержки. 
## 📋 Возможности
- **2 режима просмотра ответа** — данные отображаются в виде карточек или JSON
- **API-логины хранятся в браузере** — у каждого есть база знаний нужных ему логинов, **которые хранятся до очистки кеша**
- **Экспорт данных** — выгрузка ответов в JSON
